# foyers-impayes

Projet personnel (portfolio) : harmonisation de données, pilotage Power BI et score de risque d'entrée en impayé pour un groupe de bailleurs sociaux **fictif** (Groupe Horizon Nord).

> Les données sont **synthétiques**. Ce projet ne repose sur aucune expérience professionnelle.
